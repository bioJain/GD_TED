# Graves' Disease 및 Thyroid Eye Disease 경쟁환경 조사: 역학·진단·병기·표준치료(SoC)

**작성일**: 2026-09-14 | **범위**: 성인 환자, 글로벌 주요국 (미국·EU5·한국·일본·중국)
**산출물**: 본 보고서 + `Graves_TED_landscape.xlsx` (11개 시트, 표 전체)

## 요약 (Key Takeaways)

| 구분 | Graves' Disease (GD) | Thyroid Eye Disease (TED) |
|---|---|---|
| 유병률 | 일반 인구 약 0.5~1.5% [17] | 인구 10만 명당 25~65명 (일본~미국) [1, 2] |
| 발생률 | 약 21~27/10만/년 (덴마크·스웨덴) [16, 21] | 약 5~11/10만/년 (덴마크·미국·일본) [1, 2, 5] |
| 진단 | TSH/FT4 + TRAb(확진) [72, 73] | 임상 평가 + CAS + EUGOGO 중증도 분류 [40] |
| 병기 체계 | 공식 병기 없음 → 합병증(안병증·중독위기) 기준 중증도 | EUGOGO 3단계(경증/중등도-중증/시력위협) × CAS 활성도 [40] |
| SoC 핵심 | 항갑상선약제 1차 → 재발 시 RAI/수술 [70, 73] | 경증: 관찰·셀레늄 / 중등도-중증 활성: IV 스테로이드+마이코페놀레이트 / 시력위협: 고용량 스테로이드→감압술 [40] |
| 치료 패러다임 변화 | 60년간 불변, ATD 선호 확대 [70] | 2020년 테프로투무맙, 2026년 벨리그로투그 승인으로 표적치료 시대 개막 [92, 100, 101] |

## 3. Graves' Disease: 진단·중증도·SoC

### 3.1 진단

| 단계 | 방법 | 내용 |
|---|---|---|
| 선별 | TSH + 유리 T4/T3 | TSH 억제가 가장 민감한 소견 [72] |
| **확진** | **TSH 수용체 항체 (TRAb/TSI)** | GD 특이 생체표지자 — 감별진단·경과추적·치료 선택에 활용 [73, 71] |
| 영상 | 갑상선 초음파 | 저에코성·혹혈관성 증가; 결절 감별 [73] |
| 영상(선택) | 방사성요오드 섭취율/스캔 | 감별이 불명확할 때(무통 갑상선염, 독성 결절, 외인성 호르몬) [72] |
| 참고 | 임상 진단만의 한계 | TRAb 검사 대비 민감도 88%, 특이도 66% — 오분류 위험 [75] |

### 3.2 중증도/병기 기준

GD 자체에는 공식 병기 체계가 없으며, 임상적으로는 **갑상선 기능 상태와 합병증**으로 중증도를 구분한다:

1. **무증상/경미** — 검사 이상 중심
2. **명확한 갑상선중독증** — 오한, 체중감소, 빈맥, 떨림 등
3. **합병증 동반** — 안병증(TED), 심방세동, 골다공증, 심부전 [72]
4. **갑상선 중독위기(thyroid storm)** — 최중증 응급질환, Burch-Wartofsky/JTS 점수로 평가 [72]

### 3.3 단계별 SoC

| 단계/상황 | SoC | 근거 |
|---|---|---|
| 초기 (무합병증) | **항갑상선약제(MMI) 12~18개월** 1차 선택 + 베타차단제(증상 조절). 완해율 ~30-50% | 전 세계 임상의 90% 이상 ATD 1차 선호로 패러다임 전환 [70]; MMI 선호 [73] |
| 재발/지속 (18개월 후 고 TRAb 또는 미완해) | **방사성요오드(RAI) 또는 갑상선전절제술** (확정적 치료). 장기 저용량 MMI 유지도 안전한 대안 | [73, 69] |
| 활성 안병증 동반 | **항갑상선약제 우선, RAI 회피** (특히 흡연자). RAI 불가피 시 경구 스테로이드 예방 | [40, 69] |
| 임신 | 1기 PTU, 2기 이후 MMI 전환 가능 | [73] |
| 갑상선 중독위기 | 즉시 입원 — 대량 티오나마이드 + 요오드제 + 베타차단제 + 스테로이드 + 지지요법 | [72] |
| 한국 실정 | 초기 치료 98% ATD, RAI 0.7%, 수술 1.3%; ATD 치료실패 58.5% vs RAI 21.3% | [29, 30] |

## 4. Thyroid Eye Disease: 진단·병기·SoC

### 4.1 진단

| 구분 | 방법 | 내용 |
|---|---|---|
| 임상 평가 | 안검후퇴, 안구돌출(Hertel), 안구운동 제한, 복시, 각막노출, 시신경병증 + GO-QoL 삶의 질 | EUGOGO 표준 평가 [40] |
| 혈청 | TRAb | GD 진단 및 TED 연관 확인 [40, 46] |
| 영상 | 안와 CT (감압술 전 필수), MRI (비대칭·시신경병증 의심·감별진단) | [40] |

### 4.2 병기/중증도 기준 (EUGOGO 2021)

**활성도 — CAS (Clinical Activity Score)** [40]:

| # | 항목 |
|---|---|
| 1 | 자발적 안구통 |
| 2 | 상하 주시 시 통증 |
| 3 | 안검 충혈 |
| 4 | 결막 충혈 |
| 5 | 눈물점/눈꺼풀러 부종 |
| 6 | 안검 부종 |
| 7 | 결막 부종 (chemosis) |

- **CAS ≥ 3/7 → 활성**, < 3 → 비활성
- 10항목 확장판: 최근 1~3개월 내 ① 안구돌출 ≥2mm 증가 ② 안구운동 ≥8° 감소 ③ 시력 ≥1줄 감소 — 진행 평가용

**중증도 — EUGOGO 3단계** [40]:

| 분류 | 기준 |
|---|---|
| **경증** | 일상생활에 미미한 영향(면역조절/수술 정당화 불충분). 안검후퇴 <2mm, 경미한 연부조직 침범, 안구돌출 정상치 +3mm 미만, 무복시 또는 간헐적 복시 중 1개 이상 |
| **중등도-중증** | 시력위협은 아니나 면역억제(활성 시) 또는 수술(비활성 시)을 정당화할 정도. **이하 2개 이상**: 안검후퇴 ≥2mm, 중등도 이상 연부조직 침범, 안구돌출 정상치 +3mm 이상, 지속성/간헐적 복시 |
| **시력위협** | 시신경병증(DON) 및/또는 각막궤양·각막파열 |

*보조 체계: VISA(증상별 등급화), NOSPECS — EUGOGO가 임상·연구에서 검증된 표준 [40, 43].*

### 4.3 중증도 × 활성도별 SoC (EUGOGO 2021) [40]

| 중증도 × 활성도 | SoC |
|---|---|
| **경증 + 활성** | 위험인자 관리(**금연**), 국소치료(윤활제·선글라스·프리즘), **셀레늄**(결핍 지역). GD 치료는 항갑상선약제 우선, RAI 시 스테로이드 예방 |
| **경증 + 비활성** | 경과 관찰 + 국소치료 |
| **중등도-중증 + 활성 (1차)** | **IV methylprednisolone 중간용량(0.5g×6주 → 0.25g×6주, 누적 4.5g) + 마이코페놀레이트 소듐 0.72g/일×24주** (권장 1차). 대안: 고용량 IV MPSS 단독(누적 7.5g) — 지속성 복시·중증 안구돌출(>25mm)·중증 연부조직 침범 |
| **중등도-중증 + 활성 (2차)** | ① IV MPSS 2차 코스(누적 최대 8g) ② 경구 스테로이드+시클로스포린/아자티오프린 ③ 안와방사선치료±스테로이드 ④ 테프로투무맙 ⑤ 리툭시맙(DON 배제, 전문센터) ⑥ 토실리주맙 |
| **시력위협 (DON)** | **고용량 IV MPSS 500-1,000mg** 3일 연속 또는 격일×1주(1주 추가 가능) → 1~2주 내 무반응/악화 시 **긴급 안와감압술** |
| **시력위협 (각막)** | 중증 각막노출: 보호적 처치 점진적 시행, 각막파열 시 즉시 수술 |
| **비활성 잔여변화** | 재활 수술 순차 시행: 안와감압 → 사시수술 → 안검수술 |

## 6. 제한점 및 가정

1. **미국 GD 발생률**: 최신 인구 기반 확정치 부재 — 덴마크 검증치(26.8/10만)를 대리 적용. 미국 실제값은 이보다 높거나 낮을 수 있음.
2. **EU5·중국·한국 TED 유병률**: 직접 수치 부재 → 일본(저)·미국(고) 시나리오로 범위 제시.
3. **GD 유병률 0.5% vs 1-1.5%**: 리뷰 문헌 [17]은 1-1.5% 제시하나, 이는 여성 중심·평생 위험 포함 가능성이 있어 보수적 0.5%를 기본값으로 사용. 민감도는 표에 명시.
4. **한국 GD 유병률 0.2%**: 치료 기능항진증 기준이므로 미치료 유병은 추가될 수 있음.
5. TED 동반비율(40%)은 경증 포함 — 치료 대상(중등도 이상) 시장은 일본 청구 DB 기준 유병의 ~15% 수준으로 추정 [2].
