# Approved execution plan

Data cut: 2026-09-10

1. Freeze and audit the ClinicalTrials.gov landscape.
2. Retrieve disease, standard-of-care, regulatory, clinical, and pipeline evidence.
3. Curate all in-scope result-bearing trials with efficacy, safety, durability, and caveats.
4. Build canonical clinical-trial, pipeline-asset, standard-of-care, and evidence-claim tables.
5. Produce a Korean scientific report, six data figures, and an exact 15-slide presentation.
6. Run within-agent blinded textual QA, cross-file consistency checks, visual QA, and release hashing.

No quantitative meta-analysis or naive cross-trial pooling. R&D potential and evidence confidence remain separate. No PDF deliverable.
